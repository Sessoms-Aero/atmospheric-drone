# Atmospheric Monitoring Drone
An EE project exploring autonomous atmospheric monitoring through computer vision, environmental sensing, and embedded computing.

## Hardware
- NVIDIA Jetson Orin Nano
- Raspberry Pi Camera Module v2 NoIR (IMX219)
- ESP32 microcontroller
- Environmental sensors

## Project Objectives
- Develop real-time computer vision software
- Detect clouds and estimate cloud coverage
- Collect and analyze atmospheric sensor data
- Integrate hardware and software into an aerial monitoring platform

## Technologies
Python, Opencv, GStreamer, Linux, and embedded systems
